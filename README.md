# Mugiwara Store 🏴‍☠️

Site demonstrativo da **Mugiwara Store**, loja especializada em mangás físicos originais, edições definitivas de luxo e shonens/seinens históricos.

Projeto desenvolvido exclusivamente com **HTML5 e CSS3 puro (Zero JavaScript)**, seguindo a estética dark contrast inspirada no design moderno do X (antigo Twitter).

---

## ⚡ Destaques do Projeto

- **Zero JavaScript:** Todas as interações (modais de detalhes via `:target`, filtros de categorias via radio buttons e menu responsivo) funcionam 100% com CSS puro.
- **Fluxo de Aquisição via WhatsApp:** Sem carrinho ou checkout complexo — botões "Adquirir" direcionam diretamente para atendimento personalizado no WhatsApp com mensagens pré-formatadas.
- **Design System & Tipografia:** Tipografia unificada com **Montserrat** (Google Fonts), grid modular de 8pt, layout com contraste preto/branco e ilustrações temáticas (Luffy Gear 5 & Jolly Roger).
- **Catálogo com 12 Obras Reais:** Capas, sinopses e especificações detalhadas de Berserk, Chainsaw Man, One Piece, Vagabond, Jujutsu Kaisen, Vinland Saga, Death Note, Monster, Tokyo Ghoul, Spy x Family, Attack on Titan e Demon Slayer.
- **Responsivo:** Layout adaptável para smartphones, tablets e desktops.

## 🚀 Como Executar

Por ser um projeto puramente estático em HTML/CSS, você pode:

1. **Abrir diretamente:** Dar dois cliques no arquivo `index.html` em qualquer navegador.
2. **Ou usar um servidor local:**
   ```bash
   npx serve .
   # ou com Python:
   python -m http.server 3000
   ```
   Acesse: `http://localhost:3000`
